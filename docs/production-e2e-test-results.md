## 1. 결과 요약

프론트의 최신 화면과 핵심 모임 생성·참여·투표 흐름이 정상 동작했다. 최종 재검증에서
이전에 누락됐던 아래 운영 API 3종도 모두 정상 동작했다.

- `POST /api/invites/{inviteToken}/participants/session`
- `GET /api/meetings/{meetingId}/vote-details`
- `DELETE /api/auth/me`

## 2. 통과한 시나리오

### 2.1 공개 화면 및 인증

- 홈 화면이 정상 표시된다.
- 회원가입 후 모임 목록으로 이동한다.
- 로그아웃 후 로그인할 수 있다.
- 인증되지 않은 사용자는 보호 화면에서 로그인 화면으로 이동한다.

### 2.2 모임 생성

- 모임명, 설명, 카테고리를 입력할 수 있다.
- 후보 기간의 시작일·종료일과 응답 마감일을 선택할 수 있다.
- 날짜를 선택하면 달력이 바로 닫힌다.
- 소요 시간과 선택 가능 시간대를 설정할 수 있다.
- 생성 후 운영 도메인의 초대 링크가 발급된다.
- 생성된 모임이 내 모임 목록에 표시된다.
- 시작일을 2026년 8월 4일로 선택하면 종료일 상한이 2026년 9월 2일로 안내된다.
- 시작일과 종료일을 포함한 30일째인 9월 2일은 선택 가능하다.
- 상한을 넘는 9월 3일부터는 종료일 선택이 비활성화된다.

### 2.3 비회원 신규 참여

- 비회원 참여 화면에 닉네임, 숫자 4자리 PIN, PIN 확인 입력이 표시된다.
- PIN 확인이 일치해야 참여 버튼이 활성화된다.
- 신규 비회원 등록 후 시간 선택 화면으로 이동한다.
- PIN 평문은 이후 시간 선택 화면에 다시 표시되지 않는다.

### 2.4 시간 선택 및 제출

- 선택 시간이 0개일 때 제출 버튼이 비활성화된다.
- 시간 슬롯을 선택하면 가능 상태와 선택 개수가 갱신된다.
- 투표 제출 후 제출 완료 화면으로 이동한다.
- 제출 완료 화면에 가능·애매·불가 응답 요약이 표시된다.

### 2.5 모임장 집계 및 추천

- 참여자 수와 응답자 수가 모임 목록 및 대시보드에 반영된다.
- 히트맵의 가능 인원수가 제출 결과와 일치한다.
- 추천 시간과 가능·애매·불가 인원수가 표시된다.
- 참여자 삭제 버튼을 누르면 즉시 삭제되지 않고 확인 모달이 표시된다.
- 일정 확정 요청 후 확정 화면으로 이동한다.

### 2.6 Chrome 화면

- Chrome 연결이 정상 동작한다.
- 사이트 데이터 삭제 후 Chrome에서도 최신 PIN UI가 표시된다.
- 신규 참여와 기존 응답 불러오기 화면을 전환할 수 있다.
- 닉네임과 PIN 입력 검증이 정상 동작한다.

## 3. 이전 실패 항목 재검증

### 해결. PIN 재접속 API

최종 재검증에서 동일 닉네임과 PIN으로 세션 복원을 요청해 `200 OK`와 새로운
`participantEditToken`이 반환되는 것을 확인했다.

이전에 표시되던 `Cannot POST /api/invites/{inviteToken}/participants/session` 오류는
재현되지 않았다.

### 해결. 회원 탈퇴 API

최종 재검증에서 올바른 비밀번호와 동의 확인 후 홈으로 이동했고, 같은 계정의 재로그인이
거부되는 것을 확인했다.

이전에 표시되던 `Cannot DELETE /api/auth/me` 오류는 재현되지 않았다.

### 해결. 참여자별 투표 상세 조회

최종 재검증에서 모임장 대시보드의 선택 슬롯에 참여자 이름 `재검증게스트2`와
`가능 1명`이 정상 표시됐다.

이전에 표시되던 `참여자 상세를 불러오지 못했어요.` 오류는 재현되지 않았다.

### 해결. 일정 확정 화면

일정 확정 후 `/meetings/{meetingId}/confirmed`에서 모임명, 확정 날짜와 시간, 설명,
참여자 수가 정상 표시됐다. 캘린더 다운로드 버튼도 오류 없이 실행됐다.

### 해결. 참여자 삭제 후 재계산

가능 응답을 제출한 참여자를 삭제한 뒤 참여자 수가 `1명 → 0명`, 선택 시간의 가능 인원이
`1명 → 0명`으로 즉시 갱신됐다. 추천 결과에서도 삭제한 참여자 이름이 제거됐다.

### 통과. 비밀번호 재설정 예외 처리

- 가입된 테스트 이메일로 재설정 요청 시 메일 확인 안내 화면으로 이동했다.
- 임의의 무효 토큰으로 비밀번호 변경을 요청하면 `유효하지 않거나 만료된 링크예요.`라는
  안내가 표시됐다.

### P2. 모임 카드 접근성

모임 목록 카드가 의미 있는 링크나 버튼으로 노출되지 않아 키보드 및 접근성 도구로
상세 화면에 진입하기 어렵다.

필요 조치:

- 클릭 가능한 카드 전체를 `Link`로 구현하거나 키보드 접근 가능한 명시적 상세 링크를
  제공한다.
- 포커스 표시와 Enter 키 이동을 검증한다.

## 4. 미검증 항목

다음 항목은 필요한 외부 조건 또는 별도 테스트 데이터가 필요해 이번 테스트에서 완료하지 못했다.

- 다른 브라우저 PIN 재접속 후 기존 응답 수정 및 재제출
- 잘못된 PIN 반복 입력과 요청 제한 메시지
- 기존 `participantEditToken` 사용자의 하위 호환
- 확정된 모임에서 참여자 삭제 차단
- 비밀번호 재설정 이메일 실제 수신
- 유효한 재설정 링크로 비밀번호 변경 및 새 비밀번호 로그인
- 실제 다운로드된 캘린더 `.ics` 파일 내용 확인
- Safari 및 실제 모바일 기기 터치·드래그
- PC 시간 선택 드래그

## 5. 테스트 데이터 정리

- 테스트 중 생성한 모임은 모두 삭제했다.
- 테스트 계정 `codex-e2e-20260804-001@example.com`도 회원 탈퇴로 삭제했다.
- 확장 검증 계정 `codex-e2e-20260804-002@example.com`도 회원 탈퇴로 삭제했다.
- 기간 검증 계정 `codex-e2e-20260804-003@example.com`도 회원 탈퇴로 삭제했다.
- 탈퇴 계정의 재로그인이 거부되는 것을 확인했다.

## 6. 재검증 우선순위

1. Chrome 캐시를 비운 뒤 PIN 재접속 → 기존 응답 수정 → 재제출 UI 검증
2. 실제 수신한 링크를 사용한 비밀번호 재설정 전체 흐름
3. 확정된 모임에서 참여자 삭제 차단
4. 다운로드한 `.ics` 파일의 일정 내용 확인
5. Safari·모바일·PC 드래그 및 접근성 검증
