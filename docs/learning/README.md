# 학습 노트 (Learning Log)

프로젝트를 진행하며 배운 개념·결정·트레이드오프를 날짜별로 누적하는 폴더.
이직 면접 대비용으로, "무엇을 했나"보다 **"왜 그렇게 결정했나"** 를 기록한다.

## 사용법
- 의미 있는 작업(아키텍처 결정, 새 기술 도입, 설계 패턴 등)이 끝나면 **`/learn`** 커맨드 실행.
  → 최근 작업을 정리해 `docs/learning/YYYY-MM-DD.md` 에 추가한다.
- 특정 주제만 정리하려면 `/learn prisma 셋업` 처럼 범위를 넘긴다.
- 각 노트는 노션에 그대로 붙여넣을 수 있는 마크다운 형식.

## 파일
- `YYYY-MM-DD.md` — 그 날의 학습 노트
